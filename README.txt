NOTÍCIAS IPMO — HOME FUNCIONAL

Arquivos:
- index.html: página inicial
- noticia.html: modelo de página individual de notícia
- styles.css: identidade visual e responsividade
- app.js: menu, busca e filtros de categorias
- article.js: conteúdo demonstrativo das páginas internas
- assets/logo-ipmo.png: logo oficial fornecido, sem alteração

Como testar:
1. Abra index.html no navegador.
2. Use a busca e os filtros de categoria.
3. Clique em “Ler mais” para abrir as páginas internas.

Esta versão é front-end e está pronta para a próxima etapa: ligação com Supabase e publicação na Vercel.
